# Code of Conduct

SayQL follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, welcoming and constructive. Harassment, insults, personal attacks and
discriminatory language aren't acceptable in issues, pull requests, discussions or any other project
space.

## Reporting

If someone's behaviour is a problem, report it privately to the maintainer,
[@dithzz](https://github.com/dithzz) on GitHub. Reports are kept confidential. The maintainer may remove comments, close
discussions, or block people who break this code of conduct.
