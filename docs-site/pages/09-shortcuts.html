On Windows and Linux, use Ctrl where macOS uses ⌘.

ShortcutWhat it does
⌘TNew SQL tab on the current database
⌘SSave the tab as a script
⌘↵Run the query or script, or only the selected SQL
↵ in the Ask boxRun, once the SQL is written
⇧↵ in the Ask boxNew line
esc in the Ask boxClear the question
/ at the start of the Ask boxOpen the command menu (↑ ↓ move, ↵ or Tab pick, esc close)
/followupChange the current query
/newStart fresh, ignore the last query
/explainExplain the current query in plain English
/fixFix the current query or its error
/improveReview and improve the current query
/skill-nameAdd a saved skill's instruction to the question
⌘-click / ⇧-click a tableAdd to / pick a range of AI context
Arrow keys, ↵, escMove through, choose in and close a right-click menu
