SayQL lets you query SQL Server and Azure SQL in plain English. Ask a question and it writes T-SQL for your schema as you type.

Get started

  1. Download SayQL for macOS, Windows or Linux.
  2. Click New connection, pick SQL Server / Azure SQL (port 1433), click Test, then Save. Azure SQL needs Encrypt connection, which is on by default.
  3. Pick an AI in Settings → AI provider.
  4. Ask in the Ask box and press ↵.

Example questions

  • "Top 20 customers by total spend"
  • "Invoices overdue by more than 30 days"
  • "Tickets opened yesterday, by priority"

"Top 20 customers by total spend" might come back as:

SELECT TOP 20 c.name, SUM(o.total) AS total_spend
FROM dbo.customers c
JOIN dbo.orders o ON o.customer_id = c.id
GROUP BY c.name
ORDER BY total_spend DESC;

What keeps it safe

Read-only by default. SayQL checks every statement, and anything that could change data asks you first. SQL Server has no read-only mode, so reads run in a transaction that's always rolled back.

For production servers, use a login that can only read (db_datareader). Certificate or login trouble? See the SQL Server tips. More in Run queries safely.
