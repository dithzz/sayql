SayQL is free text-to-SQL for MySQL and MariaDB. Type a question in plain English and the SQL appears as you type, written for your tables.

Get started

  1. Download SayQL for macOS, Windows or Linux.
  2. Click New connection, pick MySQL / MariaDB (port 3306), click Test, then Save.
  3. Pick an AI in Settings → AI provider.
  4. Ask in the Ask box and press ↵.

Example questions

  • "How many orders per day this week"
  • "Users who never logged in"
  • "Average order value by country"

"How many orders per day this week" might come back as:

SELECT DATE(created_at) AS day, COUNT(*) AS orders
FROM orders
WHERE YEARWEEK(created_at, 1) = YEARWEEK(CURDATE(), 1)
GROUP BY DATE(created_at)
ORDER BY day;

What keeps it safe

Read-only by default. Reads run inside a read-only transaction, so the server itself refuses writes. Anything that could change data asks you first.

The AI sees your schema (table and column names, types, keys, enum values and row estimates), never your rows. See Ask in plain English and Run queries safely.
