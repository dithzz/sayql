# Launch checklist

You post everything yourself, from your own accounts.

## Order

Spread it out so you can reply to each one properly.

| Day | Where | When (US Eastern) |
| --- | --- | --- |
| 1 (Tue, Wed or Thu) | Show HN ([show-hn.md](show-hn.md)) | 8–10 AM |
| 1, after HN settles | AlternativeTo ([alternativeto.md](alternativeto.md)) | Any time; approval takes days |
| 2 | r/SQL ([reddit-r-sql.md](reddit-r-sql.md)) | 8–11 AM |
| 3 | r/PostgreSQL ([reddit-r-postgresql.md](reddit-r-postgresql.md)) | 8–11 AM |
| Friday | r/selfhosted megathread ([reddit-r-selfhosted.md](reddit-r-selfhosted.md)) | Morning, soon after the new thread goes up |
| The week after | Product Hunt ([product-hunt.md](product-hunt.md)) | Goes live 12:01 AM Pacific (3:01 AM Eastern); be awake for the first hours |

Product Hunt goes last so HN and Reddit feedback can shape the first comment and gallery. Avoid Friday–Sunday for HN and PH; avoid US holidays.

## Have ready

- [ ] Latest release (0.2.4) downloads and opens on macOS, Windows and Linux.
- [ ] The demo database works with no setup.
- [ ] https://sayql.dev, the docs and the downloads link all load.
- [ ] README's MCP section and roadmap match 0.2.4 (MCP now ships in the app).
- [ ] GitHub Discussions and issue templates are on.
- [ ] Explainer video on YouTube (for Product Hunt).
- [ ] Gallery images checked at 1270×760.
- [ ] A free afternoon after each post.
- [ ] Accounts with some history: HN and Reddit flag brand-new accounts.

## Replying to comments

- Reply fast in the first 2–3 hours. That's when posts live or die.
- Thank people briefly, then answer the actual point.
- Criticism: agree with what's true, say what you'll do, link an issue if you open one. Don't argue.
- "Why not just use X?": say who SayQL is for and what it does differently. Don't knock other tools.
- Bug reports: ask for OS, database and the query, then open a GitHub issue and link it.
- Security questions: be exact. Point to "How it works" in the README. If someone finds a hole, thank them and fix it in public.
- Asked about a gap (SSH, signing, history, export): say it's not there yet and ask what they'd use it for.
- Never ask for upvotes, and don't have friends upvote. HN and Reddit both penalize it.
- Write down every feature request. They're your roadmap.
