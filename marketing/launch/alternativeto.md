**Full description:**

```
SayQL turns plain English into SQL as you type. Say what you need. It knows your schema.

It reads your tables, columns and relationships, so the SQL uses your real names and joins. Follow-ups like "only Canada" edit the query you have, and failed queries are fixed automatically.

Read-only by default. Every statement is checked, reads run in a read-only transaction the database enforces, and anything that could change data asks first. The AI sees your schema, never your table rows.

Use your own key for Claude, OpenAI, Gemini, OpenRouter, Mistral, Groq, DeepSeek or any OpenAI-compatible API, or run a local model with Ollama or LM Studio.

Works with PostgreSQL, MySQL/MariaDB, SQLite, SQL Server and Azure SQL. Includes slash commands, saved skills, and an MCP server for Claude and Cursor.

No account and no telemetry. Apache-2.0.
```
